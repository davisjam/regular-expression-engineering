# Regular Expression Engineering

A research program of the [Duality Lab](https://davisjam.github.io/), led by
James C. Davis at Purdue University.

What small, widely reused program fragments reveal about portability, understandability, performance, and security.

This repository hosts the program's project site, published at
<https://davisjam.github.io/regular-expression-engineering/>.

The site is under construction.
